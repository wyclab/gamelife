# 游戏人生 · 2000 — 2026

一个横向滚动、鼠标交互点亮、支持深/浅双色主题的个人游戏与人生回忆时间轴网站（融合 Steam 科技感与 `667667.xyz` / `blog.667667.xyz` 的极简玻璃质感）。

## 核心特性

- **横向时光轴 + 丝滑操控**：支持鼠标滚轮自动横向滚动、按住画布拖拽平移、键盘 `← / →` 方向键切换、底部 Steam HUD 缩略导航一键跳转。
- **鼠标所至即点亮（60fps 追光引擎）**：
  - 背景点阵网格随指针径向点亮
  - 中央时间光轨随指针水平位置发光
  - 节点光环、光纤连线与年份水印根据鼠标距离实时唤醒
  - 卡片边框与表面玻璃高光精准跟随鼠标轨迹
- **双色主题切换**：深色科技模式（Steam 暗夜蓝 + 云川琥珀金）与浅色极简模式（`667667.xyz` 冰白 + 科技钴蓝），自动记住偏好。
- **广义游戏分类**：内置「电脑游戏」「主机·掌机」「Vibe Coding」「人生记忆」筛选与详情弹窗。

## 如何填写你的游戏与人生回忆

所有内容都集中在单个数据文件中，无需改动组件代码：

1. **编辑节点内容**：打开 `src/data/timeline.ts`，修改 `TIMELINE_NODES` 数组中的标题、年份、平台、回忆文字与标签；复制任意节点即可新增条目，节点会自动按 `year` 排序。
2. **添加游戏截图 / 老照片**：将图片放入 `public/images/` 目录（例如 `public/images/2000-fc.jpg`），然后在对应节点里填写：
   ```ts
   image: '/images/2000-fc.jpg',
   ```
   多张图片可继续加到 `gallery: ['/images/a.jpg', '/images/b.jpg']` 中，点击节点即可在详情弹窗切换浏览。
3. **隐藏示例占位标记**：将已填写完成的节点中的 `isPlaceholder: true` 删除或改为 `false`。
4. **修改站点信息与外链**：在 `src/data/timeline.ts` 顶部的 `SITE_CONFIG` 中修改标题、简介与导航链接。

## 本地运行与构建

```bash
# 安装依赖
pnpm install

# 启动本地开发预览
pnpm dev

# 构建静态站点（输出至 dist/，可直接部署到 Cloudflare Pages / Vercel / GitHub Pages）
pnpm build
```
